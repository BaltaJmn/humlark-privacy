# humwell-privacy (web of Humlark)

Public web of **Humlark** (the app called Humwell until 14-11-2026; same bundle ID `com.baltajmn.humwell`), a
hum-to-sheet-music app for iPhone. The repo and folder keep the old name on purpose (no rename, nothing pushed).
Suggested address: <https://humlark.baltajmn.dev/> (GitHub Pages from `main`, Cloudflare CNAME `humlark` to
`baltajmn.github.io`, proxied). Not published: no DNS, no new repo. The app and `store/alta.py` already point there.

Own text and own stylesheet (serif, violet), not the layout of the other apps' webs.

| Path | What it is |
|---|---|
| `index.html` | What the app does. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy: audio on device, RevenueCat purchase records. URL in the app and the App Store |
| `legal.html` | Legal notice (LSSI art. 10), owner details |
| `hw/` | Stylesheet and icons (the new icon) |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Humwell`.
